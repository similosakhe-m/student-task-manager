## Project Description

A simple Student Task Manager built using plain PHP, MySQL, HTML, and CSS. The application allows users to create, view, edit, and delete academic tasks.

## Features

- Create new tasks
- View all tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Filter incomplete tasks
- Server-side form validation
- PDO prepared statements
- Session flash messages
- htmlspecialchars() for safe output

## Assigned Challenge

The assigned challenge implemented in this project is filtering incomplete tasks.

Users can click the "Incomplete" filter to display only tasks that have not been completed.

## Project Files

- `index.php` - Displays tasks and the incomplete-task filter
- `create.php` - Creates new tasks
- `edit.php` - Edits existing tasks
- `delete.php` - Deletes tasks
- `db.php` - Connects PHP to the MySQL database
- `functions.php` - Contains reusable functions
- `database.sql` - Creates the database and tasks table
- `style.css` - Contains the page styling

## Setup

1. Create the database using `database.sql`.
2. Update the database settings in `db.php` if necessary.
3. Start a PHP/MySQL local server.
4. Open `index.php` in a browser.
